# 拍手アイコン (アニメーション WebP)

常時ループの拍手アニメーション。

`./build.sh` が `clap.webp` を作る。
192x192 / ロスレス / 背景透明 / 20 フレーム / 1 フレーム 20ms / 1 周期 400ms / `Loop Count 0` (無限ループ) / 37768 bytes。

## 素材

Twemoji の `1f44f.svg` (👏) を使う。
`https://raw.githubusercontent.com/jdecked/twemoji/main/assets/svg/1f44f.svg`

ライセンスは CC-BY 4.0。
利用する画面に帰属表記を置く。
置く 1 行はリポジトリ直下の [NOTICE](../../NOTICE) にある。

この絵文字は 3 つの path でできている。

- `#EF9645` 奥の手
- `#FFDB5E` 手前の手
- `#FA743E` 衝撃線

2 つの手が別 path なので、独立に動かせる。

## 作り直す

```sh
./build.sh
```

出力先は `OUT` で変えられる。
`OUT=../../dist/clap.webp ./build.sh` はディレクトリを作ってから書く。

パラメータは環境変数で振れる。

```sh
ROT=32 POW=1.0 SIZE=512 ./build.sh
```

| 変数 | 既定 | 意味 |
| --- | --- | --- |
| `SIZE` | 192 | 出力の 1 辺 (px) |
| `N` | 20 | 1 拍のフレーム数 |
| `DUR` | 20 | 1 フレームの表示時間 (ms)。`N * DUR` が 1 周期 |
| `ROT` | 26 | 最大開度 (度)。片手あたり |
| `PX` `PY` | 18, 40 | 回転の支点。手首側に置く |
| `POW` | 0.90 | 接触付近の鋭さ。小さいほど接触が一瞬になる |
| `WARP` | 1.0 | 時間の非対称。1 未満で開くのが速く、閉じるのが遅い |
| `FLASH` | 0.30 | 衝撃線が出ている長さ。半周期に対する比 |

`gen.py` は 2 パスで動く。
1 パス目で全フレームのバウンディングボックスの和を測り、切れない最小の viewBox を決める。
2 パス目でその viewBox を全フレームに固定して SVG を吐き、`resvg` でラスタライズする。
開度を変えても枠からはみ出ないのはこのため。

`frames/` は生成物なので追跡しない。
`frames/duration` に 1 フレームの ms を書き出し、`build.sh` がそれを読んで `img2webp -d` に渡す。
`N` と表示時間の対応が 1 箇所に収まる。

## 決めた理由

ロスレスを使う。
色数が少ないので、非可逆 (`-lossy -q 90`) だと 71342 bytes に増える。
ロスレスは 37768 bytes。
既定のパラメータで作った 20 フレームでの比較。

`webpmux -set bgcolor 0,0,0,0` を後段に挟む。
`img2webp` が書く ANIM チャンクの背景色は既定で不透明白 (`0xFFFFFFFF`) で、一部のフレームは dispose method が `background` になる。
WebP の仕様では dispose=background はこの背景色で塗る規定なので、透明のはずの領域に白が出る余地がある。
背景色を透明にすれば、どう解釈されても透明になる。

## 採らなかった方法

平行移動で両手を離す。
Twemoji の 👏 は両手がほぼ完全に重なった構図なので、軸方向に離しても「2 枚の手が横にずれる」ように見えるだけで拍手にならない。
手首を支点にした回転で扇状に開くほうが実際の動きに近い。

HTML/CSS アニメーションを headless Chrome で 1 フレームずつ撮る。
サンドボックス内では Chrome が起動しないことがある。
ProcessSingleton の unix socket の `bind()` が拒否されて abort する (`--headless` と `--headless=new` の両方)。
プロファイルを `$TMPDIR` に置いても同じ。

`ffmpeg` で WebP を書く。
`ffmpeg` は webp が decode only のビルドがあり、その場合は書けない。
`ffmpeg -encoders | grep webp` が空なら該当する。
`img2webp` を使う。

全フレームをフルキャンバスで置いて dispose を不要にする。
`img2webp` の差分矩形の最適化が失われてサイズが増える。
背景色を透明にするだけで済むので不要だった。

片方の手を左右反転して鏡像にする。
開いた状態は左右対称になって自然だが、接触フレームの重なりが崩れる。
2 つの手は重なるように形が設計されているため、反転すると手のひらの膨らみが逆側に来る。
位置の調整では直らない。

OS の絵文字フォント (Apple Color Emoji) をレンダリングして焼き込む。
macOS 外での利用に制約があるので、配布物には向かない。
Twemoji なら表記だけで通る。
