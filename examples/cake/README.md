# バースデーケーキアイコン (アニメーション WebP)

ロウソクの炎が揺れる常時ループ。

`./build.sh` が `cake.webp` を作る。
192x192 / ロスレス / 背景透明 / 20 フレーム / 1 フレーム 30ms / 1 周期 600ms / `Loop Count 0` (無限ループ) / 19024 bytes。

## 素材

Twemoji の `1f382.svg` (🎂) を使う。
`https://raw.githubusercontent.com/jdecked/twemoji/main/assets/svg/1f382.svg`

ライセンスは CC-BY 4.0。
利用する画面に帰属表記を置く。
置く 1 行はリポジトリ直下の [NOTICE](../../NOTICE) にある。

ellipse 2 と path 10 でできている。

| 範囲 | 中身 |
| --- | --- |
| 0〜1 | 皿 (`#8899A6` / `#CCD6DD`) |
| 2〜5 | ケーキ本体 (`#DD2E44` / `#F4ABBA` / `#DD2E44` / `#EA596E`) |
| 6〜7 | ロウソク 1 本目。蝋 `#FFF8E8` と炎 `#FAAA35` |
| 8〜9 | 2 本目 |
| 10〜11 | 3 本目 |

動かすのは `#FAAA35` の炎 3 つだけ。
皿とケーキ本体は固定する。

## 作り直す

```sh
./build.sh
```

出力先は `OUT` で変えられる。
`OUT=../../dist/cake.webp ./build.sh` はディレクトリを作ってから書く。

パラメータは環境変数で振れる。

```sh
AMPY=0.30 SKEW=20 ./build.sh
```

| 変数 | 既定 | 意味 |
| --- | --- | --- |
| `SIZE` | 192 | 出力の 1 辺 (px) |
| `N` | 20 | 1 周期のフレーム数 |
| `DUR` | 30 | 1 フレームの表示時間 (ms)。`N * DUR` が 1 周期 |
| `AMPY` | 0.20 | 炎の縦の伸縮 |
| `AMPX` | 0.08 | 炎の横の伸縮。縦とは逆位相 |
| `ROT` | 4 | 炎の傾きの振幅 (度) |
| `SKEW` | 14 | 炎のせん断 (度)。下端を残して先端が振れる |
| `H2` | 0.40 | 2 倍波の比率。揺らぎの不規則さ |
| `SWAY` | 0.12 | 炎の横方向のずれ (svg 単位) |

炎の支点は `gen.py` が測る。
3 本を単独でラスタライズしてバウンディングボックスを取り、下端の中央を支点にする。
実測は (25.65, 6.70) / (18.00, 9.95) / (10.35, 6.70) で、中央の 1 本だけ蝋が短く炎の位置が低い。

`gen.py` は 2 パスで動く。
1 パス目で全フレームのバウンディングボックスの和を測り、切れない最小の viewBox を決める。
2 パス目でその viewBox を全フレームに固定して SVG を吐き、`resvg` でラスタライズする。

`frames/` は生成物なので追跡しない。
`frames/duration` に 1 フレームの ms を書き出し、`build.sh` がそれを読んで `img2webp -d` に渡す。

## 決めた理由

`skewX` を足した。
支点を下端に置いた scaleY だけでは、炎が膨らんで縮む動きに見える。
下端を固定して先端だけを横に振るせん断を重ねると、揺らめきになる。

基本波に 2 倍波を重ねる (`H2`)。
単純な sin だと 3 本が同じ形で位相だけずれた動きになり、規則的に見える。
2 倍波の周期は基本波の約数なので、重ねてもループの周期は変わらない。

炎の位相は 3 本で 2π/3 ずつずらす。
同時に揺れると 3 本が連動して見える。

炎だけを動かす。
ケーキ本体と皿が固定なので、WebP のフレーム間の差分矩形が炎の周りに収まる。
4 点の中で最も軽い 19024 bytes はこれによる。

## 採らなかった方法

炎の支点を定数で書く。
3 本の下端の高さが違う (中央 9.95、両端 6.70) ので、1 つの値では中央の炎が浮くか埋まる。
ラスタライズして測る形にした。

ケーキ本体も揺らす。
炎の揺らぎと連動する理由がなく、全フレームで差分矩形が全域に広がってファイルが重くなる。
