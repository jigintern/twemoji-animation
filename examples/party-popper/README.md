# クラッカーアイコン (アニメーション WebP)

紙吹雪が飛ぶ常時ループ。

`./build.sh` が `party-popper.webp` を作る。
192x192 / ロスレス / 背景透明 / 26 フレーム / 1 フレーム 35ms / 1 周期 910ms / `Loop Count 0` (無限ループ) / 84846 bytes。

## 素材

Twemoji の `1f389.svg` (🎉) を使う。
`https://raw.githubusercontent.com/jdecked/twemoji/main/assets/svg/1f389.svg`

ライセンスは CC-BY 4.0。
利用する画面に帰属表記を置く。
置く 1 行はリポジトリ直下の [NOTICE](../../NOTICE) にある。

path 7 と circle 8 でできている。

| 範囲 | 中身 |
| --- | --- |
| 0〜2 | クラッカー本体 (`#DD2E44` / `#EA596E` / `#A0041E`) |
| 3〜6 | リボン 4 本 (`#AA8DD8` 2 本、`#77B255` 2 本) |
| 7〜14 | 紙吹雪の粒 8 個 (circle) |

粒は絵の全域に散っていて、左下寄りの 2 個 (`cx` 2.0 と 7.5) を含む。
本体の口から一方向に出ているのではなく、既に弾けた状態の絵になっている。

## 作り直す

```sh
./build.sh
```

出力先は `OUT` で変えられる。
`OUT=../../dist/party-popper.webp ./build.sh` はディレクトリを作ってから書く。

パラメータは環境変数で振れる。

```sh
SPRD=1.8 N=32 DUR=28 ./build.sh
```

| 変数 | 既定 | 意味 |
| --- | --- | --- |
| `SIZE` | 192 | 出力の 1 辺 (px) |
| `N` | 26 | 1 周期のフレーム数 |
| `DUR` | 35 | 1 フレームの表示時間 (ms)。`N * DUR` が 1 周期 |
| `SPRD` | 1.30 | 粒の飛距離。中心からの元の距離に対する倍率 |
| `RIB` | 0.35 | リボンの飛距離。`SPRD` に対する比 |
| `RIBR` | 16 | リボンの回転 (度)。飛び終わりの値 |
| `ROTB` | 5 | 本体の反動の振幅 (度) |
| `FIN` | 0.06 | 紙吹雪の立ち上がり。1 周期に対する比 |
| `HOLD` | 0.60 | 紙吹雪を完全に見せておく区間。1 周期に対する比 |
| `FOUT` | 1.0 | `HOLD` の後の消え方の鋭さ。大きいほど早く消える |
| `EASE` | 0.55 | 飛び方。1 未満で初速が速く後半で伸びが鈍る |
| `CUT` | 0.04 | この opacity を下回った要素は出力しない |
| `CX` `CY` | 18, 18 | 放射の中心 |
| `BX` `BY` | 4, 33 | 本体の回転支点。円錐の底 |
| `PAD` | 2.0 | `FIT=0` のときの viewBox の余白 (svg 単位) |
| `FIT` | 0 | 1 で全フレームを枠に収める。0 は紙吹雪が枠外に抜ける |

粒とリボンの中心は `gen.py` が測る。
各要素を単独でラスタライズしてバウンディングボックスの中心を取り、放射の起点 `(CX, CY)` からの相対位置を出す。

紙吹雪の opacity は `HOLD` まで 1 のままで、そこから `u=1` の 0 へ smoothstep で落ちる。
`u=0` と `u=1` の両方で 0 になるので、位置が継ぎ目で元に戻ってもそのとき透明でループが繋がる。
26 フレームのうち 24 フレーム (92%) で紙吹雪が見え、末尾の opacity は 0.330 / 0.202 / 0.097 と落ちる。

本体の反動は `sin(2πu) * (1-u)^1.2` の減衰振動で、両端が 0 になる。

`frames/` は生成物なので追跡しない。
`frames/duration` に 1 フレームの ms を書き出し、`build.sh` がそれを読んで `img2webp -d` に渡す。

## 決めた理由

viewBox を固定にした (`FIT=0`)。
紙吹雪が枠外へ抜けるのがクラッカーとして自然で、絵の大きさも保たれる。

飛距離を中心からの元の距離に比例させる。
全粒を同じ距離だけ動かすと、散らばりが平行移動に見えて放射にならない。

`opacity` が `CUT` を下回った要素は出力しない。
薄すぎて見えない粒がフレームに残ると、`FIT=1` のときのバウンディングボックスを無駄に広げ、WebP の差分矩形も広がる。

1 周期を 910ms にした。
紙吹雪が飛んで消えるまでを見せるので、拍手 (400ms) より長い時間が要る。

消え方を smoothstep にした。
`(1-u)` の冪だと紙吹雪が飛び始めてすぐ薄くなり、賑やかさが続かない。
冪の指数を下げて長く残そうとすると、今度は `u=1` の直前で急に落ちてループの継ぎ目が見える。
`HOLD` まで完全に見せてから smoothstep で 0 に向かわせると、両方が立つ。

`CUT` を 0.04 に下げた。
`HOLD=0.60` では末尾のフレームの opacity が 0.097 で、0.06 のままだと閾値のすぐ上になる。
`N` を変えたときに最終フレームが閾値をまたぐかどうかで、消え方が変わってしまう。

## 採らなかった方法

全フレームのバウンディングボックスの和で viewBox を決める。
拍手・蝶・ケーキと同じ方式だが、紙吹雪の飛距離ぶん枠が広がってクラッカー本体が小さくなる。
`SPRD` を上げるほど絵が縮むので、動きを強くすることと絵の大きさが競合する。
`FIT=1` で今もこの方式に切り替えられる。

本体の反動を大きくする。
支点が円錐の底 (4, 33) なので、先端 (29, 7) までの距離が 36 単位ある。
7 度で先端が 4.4 単位動き、`PAD=2` の余白では枠から出る。
5 度に抑えた。
